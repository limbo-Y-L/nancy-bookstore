### 任务3 · 安全规则（用户要求 `{read:"auth != null", write:"auth != null"}` 的 PG 等价）
- `GRANT SELECT,INSERT,UPDATE,DELETE ON public.wrongs TO authenticated`
- `ALTER TABLE public.wrongs ENABLE ROW LEVEL SECURITY`（`relrowsecurity=true`）
- 4 条 PERMISSIVE 策略，**全部 `TO authenticated`**：`wrongs_select`(USING true) / `wrongs_insert`(WITH CHECK true) / `wrongs_update`(USING+WITH CHECK true) / `wrongs_delete`(USING true)
  → 语义等价：**未登录（anon）无授权无策略 → 默认拒绝；已登录（authenticated）放行全表**。
- ⚠️ **建表时平台自动给 `anon` 授了 SELECT**（与 auth!=null 冲突）→ 已 `REVOKE ALL ON public.wrongs FROM anon`，现 anon 授权数 = 0。
- **功能验证**：`SET ROLE anon; SELECT count(*) FROM public.wrongs` → **ERROR: permission denied for table wrongs (42501)** ✅；`SET ROLE authenticated; SELECT ...` → **成功，0 行** ✅
- 最终授权面：authenticated（全）/ service_role（全）/ 表所有者（全）/ **anon 无**。
- `public` schema 用户表清单 = **仅 `wrongs`**（未动其他集合；auth.*/storage.* 系统表未碰）。
