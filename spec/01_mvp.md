## §1 范围边界（一期MVP · 含 / 不含）

| 含（In） | 不含（Out） |
|---|---|
| Web+PWA，Pad竖屏优先、手机并重、电脑兜底（响应式） | 原生App、小程序 |
| 首页素壳（title铭牌+氛围区+作业桌双入口+开眼界卡+弧线小灶进度+星练轻卡） | 精绘视觉、动效细节（N2） |
| 拍照批改结果页（已终封线框） | 真实OCR后端（Mock透传） |
| 讲题页苏格拉底闭环（已终封，AI追问不直给，翻转主讲静听） | RAG、向量库 |
| 家长态入口（右上羽毛长按，无显式底栏"我的"） | 智库管理UI（延后） |
| 全局单聊天窗双态 | 多账号、云同步 |
| 本地Mock数据驱动，无后端强依赖 | 生产部署流水线 |

## §2 黄金路径

启动 → 首页 → [作业桌·作业] → 拍照/粘贴 → 批改结果页
→ 讲题页（苏格拉底追问链）→ 翻转主讲（AI静听）→ 收束一句软话

首页 → [作业桌·口算] → 口算轻量页（阅完即退，无底操键）

首页 → 温故小灶进度卡（一期只渲染状态，不展开交互）

> 温故小灶完整交互、星练场双轨、妙语工坊全子块：MVP骨架占位，不含。

## §3 技术栈（已拍板 · 2026-10-19）

| 项 | 约定 |
|---|---|
| 框架 | **Vue3 + Vite + TypeScript** |
| 包管理 | corepack pnpm 12.14.0，`pnpm-workspace.yaml` 已设 `allowBuilds.esbuild: true` |
| 样式 | CSS变量Design Token，主色域 `#E8DFF5` 淡紫，圆角≥14px，基准字号16pt |
| 路由 | hash路由，深度≤2，返回一键回首页，无面包屑 |
| 状态 | pinia，极轻使用，不引重型 |
| 存储 | localStorage模拟投喂库（非RAG），无服务端持久化 |
| PWA | vite-plugin-pwa，manifest name=`Nancy的奇妙书屋`，display=standalone |
| Mock | `mock/` 目录，讲题流静态数组 |

## §4 公共组件（5件锁死）

| 组件 | 要点 |
|---|---|
| `<Shell>` | 顶铭牌固定 + 底栏三键常驻 |
| `<StarTrack>` | 弧线三态：done实心紫 / current呼吸 / todo浅灰描边 |
| `<SoftCard>` | 圆角淡底无阴影统一容器 |
| `<FoxHint>` | 仅讲题/翻转收束出现，不全局飘 |
| `<ParentGate>` | 长按≥800ms触发家长态，无按钮 |
