# 文案调性规约 · 奇妙书屋 voice

## §1 调性四字诀：温 · 留 · 不 · 真

| 字 | 含义 | 禁止 |
|---|---|---|
| 温 | 像深夜台灯下翻书，语气软但不嗲，有呼吸感 | 甜腻、卖萌叠字轰炸（"呀~哦~呢~"连用） |
| 留 | 句子收得住，留白给读者自己填，不把话说满 | 总结句、升华句、道理句（"所以你要…""愿你…"类） |
| 不 | 不鸡汤、不说教、不鼓励式喊话 | "加油""你真棒""继续坚持"等评价性输出 |
| 真 | 具体、有物感：纸的纹、灯光的色、翻页的轻响 | 空泛抒情（"美好的时光""闪闪发光"类空词） |

## §2 句式与用词硬约束

- 句长：主句 ≤ 18 字，整句不超 32 字
- 标点：句末用句号或自然收住；**欢迎语/铭牌类不用感叹号**
  （唯一例外：小狐彩蛋触发文案全年 ≤ 3 处可用一个 `！`）
- 人称：默认无主语或轻带"你"；**禁用"小朋友""宝贝"**
  （预设读者：少年感成年人，非幼教语境）
- 气质词库（白名单）：纸、窗、星、檐、雾、页、灯、檐影、墨痕、晚风、未读完
- 灰名单（可偶见不连排）：梦、魔法、奇迹、闪耀
  （"奇妙"仅用于项目名本身，正文正文禁用）

## §3 三类文案容器尺度

| 容器 | 场景 | 尺度 |
|---|---|---|
| 首页欢迎语 | 顶部轻句，按时段晨/午/暮/夜切换 | 一句，≤14字，纯景物，无动作指令 |
| 灵感铭牌 | SoftCard 内提示句 | 半句到一句，像书页边批注，带一点不确定感 |
| 星练场引语 | 题目前置铺场 | 一句景物 + 半句留白，不预告题型 |

## §4 反例对照

| ❌ 反例 | ✅ 正例 |
|---|---|
| 今天也要好好读书呀✨ | 灯还亮着，页还没翻完。 |
| 你超棒的，继续加油！ | 这一页，慢慢读就好。 |
| 愿星光伴你每个夜晚🌙 | 窗上又落了一颗。 |

## §5 配套产出节奏（执行备忘，非硬规则）
1. 本规约落定后 → 出首页四时段欢迎语初稿（晨/午/暮/夜各 2～3 句备选）
2. 再出灵感铭牌句库（8～12 句打底）
3. 星练场引语留待线框骨架就绪后配套写

## §6 欢迎语切换规约（2026-10-20 增补）

- 切段依据：`new Date().getHours()` 本地时钟，不接地理日落 API，无网络依赖
- 时段切分：06 ≤ h < 11:30 晨 / 11:30 ≤ h < 16:30 午 /
  16:30 ≤ h < 19:30 暮 / 其余为夜（边界含左不含右）
- 轮替策略：**固定句，不随机**；小狐彩蛋句走独立触发通道，
  不混入主欢迎语渲染位
- 锁定句（规约示例，亦为生产默认值）：

| 时段 | 锁定句 |
|---|---|
| 晨 | 灯收了，光自己进来。 |
| 午 | 光落在摊开的那页。 |
| 暮 | 影子长过书脊的时候。 |
| 夜 | 灯还亮着，页还没翻完。 |

> 注：本表为规约锁定值，非 mock 文案；实现层读取常量映射，
> 不 hardcode 于 template 行内。
